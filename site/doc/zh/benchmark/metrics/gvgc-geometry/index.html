Epipolar Geometry

本页定义三组 GVGC-style 极线几何诊断指标，用于检验生成视频相邻帧是否具备稳定的双视角极线解释 [Hartley and Zisserman, 2004]。它们只依赖 prediction 视频本身，不需要相机位姿标注或 reference video；核心问题是：局部特征对应关系是否近似满足 epipolar constraint，从而说明两帧能否被同一个 pinhole 相机模型下的相对运动解释。

在经典多视角几何中，若两帧来自同一场景、仅发生刚体相机运动，则第一帧中的点 xxx 在第二帧中的对应点 x′x'x′ 必然落在由基础矩阵 FFF 诱导的极线 l′=Fxl' = F xl′=Fx 上。生成视频若出现背景扭曲、物体局部漂移、深度层次不稳定，或相邻帧并非同一三维结构的投影，RANSAC inlier 将难以同时满足该约束，Sampson 误差会升高、inlier 比例下降。因此，极线指标提供一种轻量、可解释的双视角几何信号；但它只检查稀疏特征点的 epipolar 一致性，不能替代 MEt3R、重投影误差或重建类指标对全局三维自洽性的判断。

WorldArena 在 prediction 的采样帧上，按 pair_stride 构造相邻（或跨步）帧对，默认使用 SIFT 特征与 Lowe 比率测试进行匹配，再以 OpenCV RANSAC 估计基础矩阵 FFF。对 RANSAC inlier 计算 Sampson 误差，并统计 inlier 比例与覆盖率；若主路径失败，runtime 还可依次尝试放宽匹配阈值或 Shi-Tomasi + Lucas-Kanade 跟踪 fallback。三个子指标共享同一次 backend 分析，分别报告如下：

指标原始统计量方向
epipolar_error基础矩阵 RANSAC 后 inlier 的 Sampson 误差中位数越低越好
epipolar_inlier_rateRANSAC inlier 数 / Lowe 比率过滤后的匹配数越高越好
feature_match_coverageRANSAC inlier 数 / 较少一侧关键点数越高越好

对匹配齐次点 xi,xi′x_i, x'_ixi​,xi′​，Sampson 误差为

di=∣xi′TFxi∣(Fxi)12+(Fxi)22+(FTxi′)12+(FTxi′)22(1)d_i = \frac{|{x'_i}^{\mathsf T} F x_i|}{\sqrt{(Fx_i)_1^2 + (Fx_i)_2^2 + (F^{\mathsf T}x'_i)_1^2 + (F^{\mathsf T}x'_i)_2^2}} \tag{1}di​=(Fxi​)12​+(Fxi​)22​+(FTxi′​)12​+(FTxi′​)22​​∣xi′​TFxi​∣​(1)

每个有效帧对以 RANSAC inlier 的 did_idi​ 中位数作为 pair 级 epipolar_error；视频级取各 pair 中位数，并在 [0,5][0, 5][0,5] 上反向归一化。

每个有效帧对的 inlier 率与覆盖率为

r=#inliers#good matches,c=min⁡ ⁣(#inliersmin⁡(#kpleft,#kpright), 1)(2)r = \frac{\#\mathrm{inliers}}{\#\mathrm{good\ matches}}, \qquad c = \min\!\left(\frac{\#\mathrm{inliers}}{\min(\#\mathrm{kp}_\mathrm{left}, \#\mathrm{kp}_\mathrm{right})},\, 1\right) \tag{2}r=#good matches#inliers​,c=min(min(#kpleft​,#kpright​)#inliers​,1)(2)

视频级 epipolar_inlier_rate 与 feature_match_coverage 分别对 rrr、ccc 取均值，在 [0,1][0,1][0,1] 上恒等归一化。epipolar_error 取各有效帧对中位数的中位数，并在 [0,5][0, 5][0,5] 上反向归一化到 [0,1][0, 1][0,1]（归一化分数越高表示极线一致性越好）。若所有帧对都无法形成足够 inlier，三项均返回 not_applicable。这些指标当前为 diagnostic，单独报告，不进 headline 聚合；在弱纹理、强非刚性运动或 dynamic prompt 场景下可能频繁失效，宜与 MEt3R、重投影误差等互补阅读。
