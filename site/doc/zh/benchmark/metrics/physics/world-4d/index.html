World 4D Metrics

world_4d group 比较 predicted world 与 simulator world 在 4D 时空结构上的一致性。它比单帧 depth 更严格，因为它要求几何点和 worldline 轨迹在时间维度上持续合理。

输入

Section titled “输入”
输入用途
world_gt/points4d.npz、pred_world/points4d.npz直接提供 4D 点集时，用于 chamfer_4d
world_gt/worldlines.npz、pred_world/worldlines.npz直接提供 worldline 轨迹时，用于 worldline 指标
depth.npz、cameras.npz、mask.npz当点集或 prediction worldline 缺失时，backend 可用 depth、camera 和 mask lifting / reconstruction 得到替代 artifact
novel_time_depth.npz、novel_time_rgb.npzoptional novel-time reconstruction 指标

Section titled “chamfer_4d”

设 reference 4D 点集为 G={gi}i=1NG=\{g_i\}_{i=1}^{N}G={gi​}i=1N​，prediction 4D 点集为 P={pj}j=1MP=\{p_j\}_{j=1}^{M}P={pj​}j=1M​，其中 gi,pj∈R4g_i,p_j\in\mathbb{R}^4gi​,pj​∈R4。实现使用非平方欧氏距离：

Section titled “worldline 指标”

设第 nnn 条 reference / prediction worldline 在第 ttt 帧的 3D 坐标为：

Xn,tg,Xn,tp∈R3X^g_{n,t}, X^p_{n,t}\in\mathbb{R}^3Xn,tg​,Xn,tp​∈R3

Δn,tg=Xn,tg−Xn,0g,Δn,tp=Xn,tp−Xn,0p\Delta^g_{n,t}=X^g_{n,t}-X^g_{n,0},\qquad \Delta^p_{n,t}=X^p_{n,t}-X^p_{n,0}Δn,tg​=Xn,tg​−Xn,0g​,Δn,tp​=Xn,tp​−Xn,0p​

drift：

δn,t=∥Δn,tp−Δn,tg∥2\delta_{n,t}=\|\Delta^p_{n,t}-\Delta^g_{n,t}\|_2δn,t​=∥Δn,tp​−Δn,tg​∥2​ worldline_mean_drift=∑n,tVn,tδn,t∑n,tVn,t\mathrm{worldline\_mean\_drift} = \frac{\sum_{n,t}V_{n,t}\delta_{n,t}}{\sum_{n,t}V_{n,t}}worldline_mean_drift=∑n,t​Vn,t​∑n,t​Vn,t​δn,t​​

optional novel-time reconstruction

Section titled “optional novel-time reconstruction”

对任意 optional novel-time artifact Yg,YpY^g,Y^pYg,Yp，先沿时间截到共同长度，并取有限值集合：

V={i:finite(Yig)∧finite(Yip)}V=\{i:\mathrm{finite}(Y^g_i)\land\mathrm{finite}(Y^p_i)\}V={i:finite(Yig​)∧finite(Yip​)}

令 ri=Yip−Yigr_i=Y^p_i-Y^g_iri​=Yip​−Yig​。则：

l1=1∣V∣∑i∈V∣ri∣\mathrm{l1} = \frac{1}{|V|}\sum_{i\in V}|r_i|l1=∣V∣1​i∈V∑​∣ri​∣ charb=1∣V∣∑i∈Vri2+ϵc2,ϵc=10−3\mathrm{charb} = \frac{1}{|V|}\sum_{i\in V}\sqrt{r_i^2+\epsilon_c^2}, \qquad \epsilon_c=10^{-3}charb=∣V∣1​i∈V∑​ri2​+ϵc2​​,ϵc​=10−3

字段名前缀决定具体指标：

  • novel_time_depth_l1 / novel_time_depth_charb
  • novel_time_rgb_l1 / novel_time_rgb_charb

Core 指标

Section titled “Core 指标”
指标计算方式原始分数含义方向当前归一化
chamfer_4d对 reference 与 prediction 的 (x, y, z, t) 点集计算双向 Chamfer distance整体时空点云是否覆盖同一批 4D 几何位置。越低越好[0.0, 1.0]
worldline_l2_errorreference 与 prediction worldline 所有有效轨迹点的 3D 欧氏距离均值每个时间点的平均轨迹位置误差。越低越好[0.0, 1.0]
worldline_mean_drift比较每条轨迹相对于起点的位移，取有效点平均轨迹形状和累计运动是否与 reference 一致。越低越好[0.0, 1.0]
worldline_final_drift每条轨迹最后一个有效点的 drift，再取平均rollout 末端是否积累了明显轨迹偏差。越低越好[0.0, 1.0]
worldline_fail_ratefinal drift 超过 evaluator 阈值的轨迹占比轨迹失败率。越低越好[0.0, 1.0]
worldline_length每条 worldline 在 rollout 中保持有效的平均长度或覆盖率轨迹完整度，反映能否持续跟踪到后续帧。越高越好[0.0, 1.0]

worldline_fail_rate 和 worldline_length 的当前底层 evaluator raw 输出是百分数。当前 WorldArena normalization 表仍写成 [0, 1]，自定义 evaluator 或配置需要确保 raw convention 与 normalization 一致。

Optional 指标

Section titled “Optional 指标”
指标计算方式原始分数含义方向
novel_time_depth_l1prediction 与 reference 的 novel_time_depth 做 L1 重建误差未纳入 core rollout 时间点的 depth 外推/插值误差。越低越好
novel_time_depth_charbprediction 与 reference 的 novel_time_depth 做 Charbonnier 重建误差对异常值更稳健的 novel-time depth 误差。越低越好
novel_time_rgb_l1prediction 与 reference 的 novel_time_rgb 做 L1 重建误差未纳入 core rollout 时间点的 RGB 重建误差。越低越好
novel_time_rgb_charbprediction 与 reference 的 novel_time_rgb 做 Charbonnier 重建误差对异常值更稳健的 novel-time RGB 误差。越低越好

启用 optional novel-time 指标时，world_gt/ 和 pred_world/ 都必须提供对应 artifact，并在自定义配置中声明 normalization。

适合解读的问题

Section titled “适合解读的问题”
  • 预测是否形成了连续、可追踪的 4D 世界结构。
  • 物体轨迹是否随时间持续接近 simulator reference。
  • 长 rollout 末端是否发生累计漂移。

不适合单独解读的问题

Section titled “不适合单独解读的问题”
  • 4D 点集正确不保证 prompt、材质或视觉质量正确。
  • lifting / reconstruction 依赖 depth、camera、mask artifact 的质量。
  • chamfer_4d 是集合距离，不直接保留一一对应的物体身份。

常见失败形态

Section titled “常见失败形态”
  • 预测 depth 或 camera 错误导致 lifted points 偏移，chamfer_4d 上升。
  • worldline 中途丢失或无效，worldline_length 下降。
  • 轨迹形状正确但整体 scale 错，worldline_l2_error 和 drift 指标都会变差。
