Long-Sequence 指标

WorldArena 内置了 Long-Sequence backend，用来从完整 prediction video 中提取长时运动和画质信号。 这组指标并非仅考察单帧或相邻两帧，而是将生成视频划分为多个短 clip，并进一步分析更长 horizon 上的运动连续性和视觉质量。

它主要回答的问题是：生成视频在更长 horizon 上是否还能保持运动连续性和画质。

这组指标是 prediction-only 指标，不使用 benchmark reference rollout，也不需要标注。 因此它们更适合解释长视频退化模式，例如运动停滞、突兀时间伪影、画质随时间下降等。

覆盖的指标

Section titled “覆盖的指标”
指标名包装后的 Long-Sequence 维度在 WorldArena 中的角色
long_sequence_motion_smoothnessmotion_smoothness基于视频插帧误差的运动平滑度
long_sequence_dynamic_degreedynamic_degree基于光流强度的运动是否充分发生
long_sequence_aesthetic_qualityaesthetic_quality基于无参考美学模型的视觉审美质量
long_sequence_imaging_qualityimaging_quality基于 MUSIQ 的成像清晰度和退化质量

原理说明

Section titled “原理说明”

普通短程指标容易漏掉只在更长 rollout 后出现的问题。 Long-Sequence backend 会先把完整视频切成多个短 clip，然后把原生 long-video 例程用于运动和画质维度。

motion_smoothness 用 AMT-S 做中间帧插值，比较插值结果和真实中间帧的差异。 dynamic_degree 用 RAFT 估计光流强度，判断视频是否有足够运动。 aesthetic_quality 和 imaging_quality 分别使用质量模型对每个 clip 的帧进行无参考打分。

具体算法

Section titled “具体算法”
  1. WorldArena 读取完整 prediction video，并在临时 workspace 中准备 Long-Sequence 输入目录。
  2. worldarena.benchmark.long_video 会把长视频切成 split_clip/，并生成每个维度需要的最小 manifest。
  3. dispatcher 根据请求维度调用对应实现：
    • motion_smoothness：AMT-S 插帧后比较预测中间帧和真实中间帧。
    • dynamic_degree：RAFT 估计光流，并统计高运动 transition 是否达到阈值。
    • aesthetic_quality：无参考 aesthetic scorer 对 clip 帧打分。
    • imaging_quality：MUSIQ 对 clip 帧打分。
  4. 每个 WorldArena 指标只读取自己对应的 wrapped dimension。
  5. wrapper 会记录运行时元数据，包括实际 device、source root、clip 数量、per-video scores 和维度特定细节。
  6. 最后每个指标按 config/benchmark.yaml 中的 [0,1] 范围独立归一化；这四个指标都是越高越好。

关键公式

Section titled “关键公式”

对 motion_smoothness，AMT-S 会用偶数采样帧插值得到中间帧，并和真实中间帧比较平均绝对差：

运动平滑度 ssmooth=clamp⁡(255−mean⁡(∣Imidreal−Imidinterp∣)255,0,1)s_{\mathrm{smooth}} = \operatorname{clamp} \left( \frac{255-\operatorname{mean}(|I^{real}_{mid}-I^{interp}_{mid}|)}{255}, 0, 1 \right)ssmooth​=clamp(255255−mean(∣Imidreal​−Imidinterp​∣)​,0,1)

对 dynamic_degree，RAFT 会估计相邻采样帧之间的光流，并取光流幅值最高的 5% 像素均值作为 transition motion score。 当超过运动阈值的 transition 数量达到计数阈值时，该 clip 记为有动态，输出 1.0；否则输出 0.0。

对 aesthetic_quality 和 imaging_quality，backend 分别对每个 clip 的帧计算无参考质量分数，再对 clip、video 和整批样本求平均。

代表性同 Case 对比

Section titled “代表性同 Case 对比”

每个展示块先给出该 case 的 input image 和完全一致的展示 prompt，然后比较模型生成结果。paired 展示必须满足 input image 相同、prompt 文本相同，并且一个模型高分、一个模型低分。若当前正式快照中该 metric 没有这种跨模型同 case pair，则单独展示高分/低分极值样例，不把它们伪装成同 case 对比。 机器可读 paired 导出： docs/assets/metric_examples/paired_manifest.csv.
