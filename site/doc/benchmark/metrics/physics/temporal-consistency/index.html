Temporal Consistency Metrics

The temporal_consistency group checks adjacent-frame geometry, optical flow, and RGB self-consistency. It asks whether the prediction evolves continuously over time rather than whether each frame is plausible in isolation.

Inputs

Section titled “Inputs”
InputUse
world_gt/depth.npz, pred_world/depth.npzdepth-warp metrics
world_gt/flow.npz, pred_world/flow.npzflow error and warping
world_gt/occlusion.npz, world_gt/mask.npzoptional valid regions for excluding occluded or invalid flow areas
prediction videorgb_warp_charb and optional rgb_warp_lpips

Formulas

Section titled “Formulas”

The implementation uses bilinear sampling for warping. Given a frame tensor XtX_tXt​ and flow Ft(x)=(ut(x),vt(x))F_t(x)=(u_t(x), v_t(x))Ft​(x)=(ut​(x),vt​(x)), warp is:

W(Xt,Ft)(x)=Xt(x+Ft(x))W(X_t,F_t)(x)=X_t(x+F_t(x))W(Xt​,Ft​)(x)=Xt​(x+Ft​(x))

Out-of-bounds samples use border padding. The Charbonnier penalty is:

ρϵ(z)=z2+ϵc2,ϵc=10−3\rho_\epsilon(z)=\sqrt{z^2+\epsilon_c^2}, \qquad \epsilon_c=10^{-3}ρϵ​(z)=z2+ϵc2​​,ϵc​=10−3

depth_warp_l1 / depth_warp_charb

Section titled “depth_warp_l1 / depth_warp_charb”

Let reference flow be FtgF^g_tFtg​, reference depth be DtgD^g_tDtg​, and prediction depth be DtpD^p_tDtp​. The implementation uses:

S=min⁡(TFg,TDp−1,TDg−1)S=\min(T_{F^g}, T_{D^p}-1, T_{D^g}-1)S=min(TFg​,TDp​−1,TDg​−1)

For each t=1,…,St=1,\ldots,St=1,…,S, the valid pixel set is:

Vt={x:finite(W(Dtp,Ftg)(x))∧finite(Dt+1,xg)∧Dt+1,xg>ϵ∧At,x}V_t = \left\{x: \mathrm{finite}(W(D^p_t,F^g_t)(x)) \land \mathrm{finite}(D^g_{t+1,x}) \land D^g_{t+1,x}>\epsilon \land A_{t,x} \right\}Vt​={x:finite(W(Dtp​,Ftg​)(x))∧finite(Dt+1,xg​)∧Dt+1,xg​>ϵ∧At,x​}

where At,xA_{t,x}At,x​ comes from non-occluded world_gt/occlusion.npz regions or adjacent-mask intersections; if neither is available, At,x=1A_{t,x}=1At,x​=1. Define:

et,x=W(Dtp,Ftg)(x)−Dt+1,xge_{t,x}=W(D^p_t,F^g_t)(x)-D^g_{t+1,x}et,x​=W(Dtp​,Ftg​)(x)−Dt+1,xg​

The implementation averages per timestep first, then averages over timesteps with at least one valid pixel. Let that set be T\mathcal{T}T:

depth_warp_l1=1∣T∣∑t∈T1∣Vt∣∑x∈Vt∣et,x∣\mathrm{depth\_warp\_l1} = \frac{1}{|\mathcal{T}|} \sum_{t\in\mathcal{T}} \frac{1}{|V_t|} \sum_{x\in V_t}|e_{t,x}|depth_warp_l1=∣T∣1​t∈T∑​∣Vt​∣1​x∈Vt​∑​∣et,x​∣ depth_warp_charb=1∣T∣∑t∈T1∣Vt∣∑x∈Vtρϵ(et,x)\mathrm{depth\_warp\_charb} = \frac{1}{|\mathcal{T}|} \sum_{t\in\mathcal{T}} \frac{1}{|V_t|} \sum_{x\in V_t}\rho_\epsilon(e_{t,x})depth_warp_charb=∣T∣1​t∈T∑​∣Vt​∣1​x∈Vt​∑​ρϵ​(et,x​)

rgb_warp_charb

Section titled “rgb_warp_charb”

Let prediction RGB be Pt∈[0,1]C×H×WP_t \in [0,1]^{C\times H\times W}Pt​∈[0,1]C×H×W, and prediction flow be FtpF^p_tFtp​. For:

S=min⁡(TFp,TP−1)S=\min(T_{F^p}, T_P-1)S=min(TFp​,TP​−1)

define:

Et,c,x=W(Pt,Ftp)c,x−Pt+1,c,xE_{t,c,x}=W(P_t,F^p_t)_{c,x}-P_{t+1,c,x}Et,c,x​=W(Pt​,Ftp​)c,x​−Pt+1,c,x​

If a valid mask BtB_tBt​ exists, it is expanded across channels; otherwise Bt=ΩB_t=\OmegaBt​=Ω. Timesteps with Bt=∅B_t=\varnothingBt​=∅ are skipped. Let the remaining timesteps be T\mathcal{T}T:

rgb_warp_charb=1∣T∣∑t∈T1C∣Bt∣∑c=1C∑x∈Btρϵ(Et,c,x)\mathrm{rgb\_warp\_charb} = \frac{1}{|\mathcal{T}|} \sum_{t\in\mathcal{T}} \frac{1}{C|B_t|} \sum_{c=1}^{C}\sum_{x\in B_t} \rho_\epsilon(E_{t,c,x})rgb_warp_charb=∣T∣1​t∈T∑​C∣Bt​∣1​c=1∑C​x∈Bt​∑​ρϵ​(Et,c,x​)

epe / fl_all / one_px_out

Section titled “epe / fl_all / one_px_out”

Let reference and prediction flow be Ft,xg,Ft,xp∈R2F^g_{t,x}, F^p_{t,x}\in\mathbb{R}^2Ft,xg​,Ft,xp​∈R2. The valid set is:

V={(t,x):finite(Ft,xg)∧finite(Ft,xp)∧At,x}V=\{(t,x): \mathrm{finite}(F^g_{t,x}) \land \mathrm{finite}(F^p_{t,x}) \land A_{t,x}\}V={(t,x):finite(Ft,xg​)∧finite(Ft,xp​)∧At,x​}

Endpoint error and reference flow magnitude:

et,x=∥Ft,xp−Ft,xg∥2,mt,x=∥Ft,xg∥2e_{t,x}=\|F^p_{t,x}-F^g_{t,x}\|_2,\qquad m_{t,x}=\|F^g_{t,x}\|_2et,x​=∥Ft,xp​−Ft,xg​∥2​,mt,x​=∥Ft,xg​∥2​ epe=1∣V∣∑(t,x)∈Vet,x\mathrm{epe} = \frac{1}{|V|} \sum_{(t,x)\in V} e_{t,x}epe=∣V∣1​(t,x)∈V∑​et,x​

Outlier indicator:

ot,x=1[et,x>3.0∧et,xmax⁡(mt,x,ϵ)>0.05]o_{t,x} = \mathbf{1} \left[ e_{t,x}>3.0 \land \frac{e_{t,x}}{\max(m_{t,x},\epsilon)}>0.05 \right]ot,x​=1[et,x​>3.0∧max(mt,x​,ϵ)et,x​​>0.05]

The current evaluator returns raw percentages:

fl_all=100⋅1∣V∣∑(t,x)∈Vot,x\mathrm{fl\_all} = 100\cdot \frac{1}{|V|} \sum_{(t,x)\in V} o_{t,x}fl_all=100⋅∣V∣1​(t,x)∈V∑​ot,x​ one_px_out=100⋅1∣V∣∑(t,x)∈V1[et,x>1.0]\mathrm{one\_px\_out} = 100\cdot \frac{1}{|V|} \sum_{(t,x)\in V} \mathbf{1}[e_{t,x}>1.0]one_px_out=100⋅∣V∣1​(t,x)∈V∑​1[et,x​>1.0]

Core Metrics

Section titled “Core Metrics”
MetricComputationRaw score meaningDirectionCurrent normalization
depth_warp_l1warp pred_depth[t] to the next frame with reference flow, then compare with gt_depth[t+1] using L1 errorWhether predicted depth evolves to the correct next-frame geometry under the simulator motion field.lower is better[0.0, 1.0]
depth_warp_charbsame alignment as depth_warp_l1, using a Charbonnier penaltyA more outlier-robust cross-frame depth warp error.lower is better[0.0, 1.0]
rgb_warp_charbwarp prediction RGB frame t with prediction flow and compare with prediction RGB frame t+1Self-consistency between the predicted video and predicted flow; it does not directly compare reference RGB.lower is better[0.0, 0.5]
epeendpoint error between pred_flow and gt_flowMean optical-flow vector error in pixels.lower is better[0.0, 10.0]
fl_allfraction or percentage of valid flow pixels satisfying the flow-outlier conditionKITTI-style flow outlier rate, usually requiring EPE greater than 3 px and relative error greater than 5%.lower is better[0.0, 1.0]
one_px_outfraction or percentage of valid flow pixels with EPE greater than 1 pxA stricter one-pixel outlier rate exposing small-motion and boundary instability.lower is better[0.0, 1.0]

The current backend evaluator returns raw percentages for fl_all and one_px_out. The current WorldArena normalization table still declares [0, 1]; custom evaluators or configs must keep the raw convention and normalization consistent.

Enabling rgb_warp_lpips requires the LPIPS runtime dependency and a custom normalization entry.

Good For

Section titled “Good For”
  • Checking whether adjacent-frame depth and flow are continuous.
  • Checking whether the predicted motion field explains the prediction’s own RGB evolution.
  • Detecting instability around motion boundaries, occlusions, and fast motion.

Not Enough For

Section titled “Not Enough For”
  • rgb_warp_charb is prediction self-consistency; flow and RGB can be wrong together and still look consistent.
  • Flow metrics depend on flow artifact quality.
  • This group does not directly judge prompt adherence.

Common Failures

Section titled “Common Failures”
  • Teleportation or skipped motion increases depth-warp error and flow outliers.
  • Prediction flow does not match RGB motion, increasing rgb_warp_charb.
  • Occlusion handling is inconsistent, increasing boundary EPE or one-pixel outliers.
