# WorldArena

WorldArena 是一个面向 world model 的基准评测与数据分析工作区。仓库的组织方式使得评测逻辑、适配器契约、第三方仓库和缓存 checkpoint 可以彼此独立演进。

如果你是第一次接触这个仓库，建议按下面顺序阅读中文文档：

- **架构**：仓库边界、任务家族、统一模型配置，以及本地模型和 API 模型如何落在同一套契约中。
- **基准评测**：评测范围、指标集合、报告契约和输出产物。
- **运行时布局**：`cache/`、`thirdparty/`、checkpoint 和模型适配仓库应如何接线。
- **数据分析**：集合规模、标注覆盖率、掩码覆盖率、caption 分布、层级视图和可下载汇总。
- **开发**：维护者工作流、校验命令和发布卫生要求。

!!! tip "推荐第一步"
    建议先阅读 benchmark 工作流和 `config/models/` 下的模型配置，它们定义了本仓库公开的核心契约。
