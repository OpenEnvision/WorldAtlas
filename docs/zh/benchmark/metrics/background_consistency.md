# 背景一致性

`background_consistency` 用来衡量预测视频在时间上的背景式稳定性。

## 它测什么

- 场景布局和背景外观的跨帧稳定性
- 预测内部的时间自一致性
- 一个粗粒度的诊断信号，用来看背景或环境是否在不该变的时候闪烁或跳变

## 当前算法

1. 使用 `openai/clip-vit-base-patch16` 的图像编码器对预测采样帧做编码。
2. 对每个后续帧 `f_i`，分别计算：
    - 与前一帧特征的 cosine similarity
    - 与首帧特征的 cosine similarity
3. 负的 cosine 会被截断到 0。
4. 每个时间步的分数是这两个相似度的平均值。
5. 原始分数是整段视频所有时间步分数的平均值。

当前接入保持得比较克制：它**不会**显式分割背景，因此更准确地说，它是一个整帧稳定性探针，而不是纯背景-only 指标。

## 输入与输出

| 项目 | 当前实现 |
| --- | --- |
| 预测输入 | 预测的采样帧 |
| 参考输入 | 无 |
| 标注输入 | 无 |
| 原始输出 | `[0, 1]` 内的整帧自一致性标量 |
| 归一化输出 | 根据配置做可选归一化后的标量 |
| 细节字段 | `transition_scores`、帧索引元数据 |
| 失败方式 | 如果 CLIP 不可用或帧数不足两帧，则返回空值和错误字符串 |

## 集成状态

| 项目 | 结论 |
| --- | --- |
| 当前聚合 | 仅 `diagnostic` |
| 论文可用性 | `仅作辅助` |

- 它的价值：可以便宜地探测时间闪烁和场景不稳定。
- 它的限制：整帧 CLIP 相似度只能算背景稳定性的粗代理。
- 建议用法：和 `subject_consistency`、`motion_smoothness` 一起读。
