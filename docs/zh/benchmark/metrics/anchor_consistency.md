# Anchor Consistency

`anchor_consistency` 是一个相对参考结果的漂移探针，用来问：预测结果相对于参考的外观相似度，是否从早期锚点到晚期锚点保持稳定。

## 这个指标测什么

- 相对参考的外观相似度是否随时间发生变化
- 晚期锚点是否比早期锚点更偏离参考
- 它不是只看预测结果自身的 self-consistency，也不是语义正确性指标

## 具体算法

1. WorldArena 会把每个预测锚点帧与同一协议位置的参考锚点帧配对。
2. 每一对图像都经过同一个 CLIP 图像编码器，计算 embedding 余弦相似度。
3. 单对分数定义为 `sim_i = clamp((cos_i + 1) / 2, 0, 1)`。
4. 原始指标值为 `raw = mean_i sim_i`。
5. 额外记录 `late_minus_early = sim_last - sim_first`。
6. 由于输出本来就在 `[0, 1]`，当前 benchmark 归一化是恒等映射。

## 输入与输出

| 项目 | 当前实现 |
| --- | --- |
| 预测输入 | 预测锚点帧 |
| 参考输入 | 配对的参考锚点帧 |
| 标注输入 | 无 |
| 原始输出 | `[0, 1]` 上的单个标量平均锚点相似度 |
| 归一化输出 | 同一个 `[0, 1]` 标量 |
| 细节字段 | `frame_scores`、`late_minus_early`、`frame_indices`、`sampled_frame_indices` |
| 失败形式 | 如果 CLIP backend 不可用，则返回 `raw = null`、`normalized = null` 和错误字符串 |

## 当前集成是否足够严格

| 项目 | 结论 |
| --- | --- |
| 当前聚合状态 | 永远是 `diagnostic` |
| 论文可用性结论 | `暂不建议直接发表` |

- 这个指标对定位外观漂移很有用，但它不是 benchmark 级的正确性指标。
- 它仍然是“相对参考”的分数，所以会奖励复制，也可能惩罚本来可以接受的受控变化。
- 建议用法：只在排查时间上的外观漂移时阅读 `late_minus_early`，不要用它给论文做模型排名。
