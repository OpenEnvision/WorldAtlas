# 深度准确性

`depth_accuracy` 用来衡量预测帧和参考帧在单目深度场上的一致程度。
它不会使用真实深度标注，而是把预测帧和参考帧都送入同一个 Depth Anything V2 单目深度模型，比较两边估计出的相对深度结构是否接近。
这个指标关注的是生成结果是否保留了参考中的前后层次、近远关系和大体几何布局。

## 它测什么

- 预测与参考之间的相对深度一致性。
- 通过单目深度代理看到的几何相似性。
- 生成结果是否保留了大体的前后层次结构。
- 它不是 metric-depth 真值评测，也不是相机轨迹或 3D 重建准确率。

## 原理说明

单目深度模型通常能较好捕捉画面中的相对深度关系，例如前景物体是否更近、背景是否更远、场景中的层次是否合理。
`depth_accuracy` 利用这一点，把 prediction 和 reference 的对齐帧分别转换成深度图，然后比较两张深度图的形状是否一致。


由于单目深度的绝对尺度可能不可靠，WorldArena 不直接比较原始深度数值。
它会先用中位数比例把预测深度缩放到参考深度的尺度，再计算 AbsRel 误差。
这样可以减少全局尺度偏差的影响，让指标更关注深度结构是否相似。

## 当前算法

1. WorldArena 按对齐时间索引配对预测帧和参考帧。
2. 如果分辨率不一致，会先把预测帧 resize 到参考帧分辨率。
3. 两边都送入 `ckpt/` 下由 `depth-anything/Depth-Anything-V2-Small-hf` 统一解析出的本地 Depth-Anything checkpoint。
4. 深度后端会输出 `predicted_depth`，并用 bicubic resize 回原始帧大小。
5. 对每对帧，先用中位数比例把预测深度对齐到参考深度。
6. 然后计算帧级 `AbsRel = mean(|d_pred - d_ref| / d_ref)`。
7. 只在参考深度大于 `1e-3` 的有效区域上求均值；如果没有有效区域，则退回到整张图。
8. 原始分数是所有帧 `AbsRel` 的平均值，因此越低越好。

## 误差公式

对第 \(i\) 对预测帧和参考帧，Depth Anything V2 预测出的深度图分别记为 \(D_i^{pred}\) 和 \(D_i^{ref}\)。
先用中位数比例估计尺度对齐系数：

!!! info "尺度对齐"

    \[
    \alpha_i
    =
    \frac{
        \operatorname{median}(D_i^{ref})
    }{
        \max(\operatorname{median}(D_i^{pred}), 10^{-6})
    }
    \]

对齐后的预测深度为：

!!! info "对齐深度"

    \[
    \tilde{D}_i^{pred}
    =
    \alpha_i D_i^{pred}
    \]

有效区域定义为：

!!! info "有效像素集合"

    \[
    \Omega_i
    =
    \{(x,y)\mid D_i^{ref}(x,y)>10^{-3}\}
    \]

帧级 AbsRel 误差为：

!!! info "帧级 AbsRel"

    \[
    e_i
    =
    \frac{1}{|\Omega_i|}
    \sum_{(x,y)\in\Omega_i}
    \frac{
        \left|
            \tilde{D}_i^{pred}(x,y)-D_i^{ref}(x,y)
        \right|
    }{
        \max(D_i^{ref}(x,y),10^{-6})
    }
    \]

最终视频或样本级深度误差是所有配对帧的平均值：

!!! info "最终误差"

    \[
    e_{\mathrm{depth}}
    =
    \frac{1}{N}
    \sum_{i=1}^{N}
    e_i
    \]

其中，\(N\) 是成功配对的帧数。
误差越小，表示预测和参考的相对深度结构越接近；归一化分数会把较小的误差映射成较高的诊断分数。

## 输入与输出

| 项目 | 当前实现 |
| --- | --- |
| 预测输入 | 预测的采样帧 |
| 参考输入 | 参考的采样帧 |
| 标注输入 | 无 |
| 原始输出 | 单个平均 `AbsRel` 误差 |
| 归一化输出 | 按 `config/benchmark.yaml` 的 `[0,1]` 范围反向缩放后的诊断分数，越高越好 |
| 细节字段 | `model_name`、`frame_absrel`、帧索引元数据 |
| 失败方式 | 如果深度后端不可用，则返回空值和错误字符串 |

## 集成状态

| 项目 | 结论 |
| --- | --- |
| 当前聚合 | 仅 `diagnostic` |
| 论文可用性 | `仅作辅助` |

- 它的价值：能补足普通外观指标看不到的几何信息。
- 它的限制：两边深度都是估计出来的，不是深度真值。
- 它对全局尺度不敏感，因为预测深度会先按中位数对齐到参考深度。
- 建议用法：作为几何侧附录指标，和 `reprojection_error`、`depth_collision` 一起报告。
