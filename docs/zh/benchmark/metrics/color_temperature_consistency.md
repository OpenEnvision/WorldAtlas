# 色温一致性

`color_temperature_consistency` 衡量预测视频的全局色调平衡是否随时间漂移。

## 衡量内容

- rollout 过程中的色偏不稳定
- 会破坏视频观感一致性的全局 hue drift
- HSV 空间里的色温代理指标，而不是校准后的 Kelvin 色温测量

该指标参考 iWorld-Bench 的 Color Temperature 指标槽位；公开说明提到了 HSV hue drift 惩罚。由于官方实现尚未公开，这里只作为 WorldArena 本地诊断指标。

## 计算流程

1. 读取预测视频的采样帧。
2. 将每帧从 RGB 转为 HSV。
3. 在单位圆上对 hue 向量做加权平均，得到每帧的全局 hue。
4. 像素权重为 `saturation ** saturation_power * value`，因此高饱和且可见的区域权重更高。
5. 计算相邻帧 hue 的圆周距离，范围为 `[0, 1]`。
6. 用指数核把加权平均 hue drift 映射成分数。

## 输入与输出

| 项目 | 当前实现 |
| --- | --- |
| 预测输入 | 预测视频采样帧 |
| 参考输入 | 无 |
| 标注输入 | 无 |
| 原始输出 | `[0, 1]` 标量；越高表示 hue drift 越小 |
| 归一化输出 | 默认配置下为恒等映射 |
| 细节字段 | 每帧 hue 角度、hue 可靠度权重、相邻 hue 距离、核参数 |
| 失败模式 | 少于两帧或没有足够饱和的相邻帧对时，返回 `raw = null`、`normalized = null` 和错误信息 |

## 集成状态

| 项目 | 判断 |
| --- | --- |
| 当前聚合 | 仅 `diagnostic` |
| 论文报告定位 | 辅助诊断 |

- 作用：能发现帧间色温跳变和全局色偏漂移。
- 局限：HSV hue 是代理信号，不是白点或 Kelvin 色温估计。
- 建议：作为低层视觉稳定性诊断，不单独作为色彩科学结论。
