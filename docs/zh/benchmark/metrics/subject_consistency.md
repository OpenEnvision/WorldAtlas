# 主体一致性

`subject_consistency` 用来衡量预测视频里的主体在时间上是否保持稳定。

## 它测什么

- 预测内部主体身份的跨帧稳定性
- 纯粹的时间自一致性，而不是相对参考的正确性
- 主体是否在时间上漂移、变形或被悄悄替换

## 当前算法

1. 使用 `facebook/dinov2-base` 对预测采样帧做特征编码。
2. 对每个后续帧 `f_i`，分别计算：
    - 与前一帧特征的 cosine similarity
    - 与首帧特征的 cosine similarity
3. 负的 cosine 会被截断到 0。
4. 每个时间步的分数是这两个相似度的平均值。
5. 原始分数是整段视频所有时间步分数的平均值。

## 输入与输出

| 项目 | 当前实现 |
| --- | --- |
| 预测输入 | 预测的采样帧 |
| 参考输入 | 无 |
| 标注输入 | 无 |
| 原始输出 | `[0, 1]` 内的主体自一致性标量 |
| 归一化输出 | 根据配置做可选归一化后的标量 |
| 细节字段 | `transition_scores`、帧索引元数据 |
| 失败方式 | 如果 DINOv2 不可用或帧数不足两帧，则返回空值和错误字符串 |

## 集成状态

| 项目 | 结论 |
| --- | --- |
| 当前聚合 | 仅 `diagnostic` |
| 论文可用性 | `仅作辅助` |

- 它的价值：能抓到 prompt/质量指标经常漏掉的 identity drift。
- 它的限制：没有显式 subject mask，也没有身份真值监督，本质仍是自代理。
- 建议用法：把它当作时间稳定性诊断，而不是 headline correctness metric。
