# 亮度一致性

`brightness_consistency` 衡量生成视频的全局亮度是否随时间保持稳定。

## 衡量内容

- 帧间亮度闪烁
- 采样预测帧上的整体曝光稳定性
- 语义或控制指标不一定能捕捉到的低层视觉质量问题

## 计算流程

1. 读取预测视频的采样帧。
2. 对每帧计算 Rec. 709 平均亮度：
   \(Y = 0.2126R + 0.7152G + 0.0722B\)。
3. 计算相邻帧的绝对亮度差。
4. 同时用相邻帧中较大的亮度值和暗部下限计算相对亮度差。
5. 用指数核把绝对漂移和相对漂移分别映射成相似度。
6. 原始分数是两种相似度的几何平均。

## 输入与输出

| 项目 | 当前实现 |
| --- | --- |
| 预测输入 | 预测视频采样帧 |
| 参考输入 | 无 |
| 标注输入 | 无 |
| 原始输出 | `[0, 1]` 标量；越高表示亮度越稳定 |
| 归一化输出 | 默认配置下为恒等映射 |
| 细节字段 | 每帧亮度、相邻绝对/相对差、平均差值、核参数 |
| 失败模式 | 少于两帧时返回 `raw = null`、`normalized = null` 和错误信息 |

## 集成状态

| 项目 | 判断 |
| --- | --- |
| 当前聚合 | 仅 `diagnostic` |
| 论文报告定位 | 辅助诊断 |

- 作用：能发现明显的曝光跳变和亮度闪烁。
- 局限：它不知道亮度变化是否来自合理的光照转场。
- 建议：作为 quality 维度的辅助诊断，与 `perceptual_quality`、`style_consistency`、`sharpness_retention` 一起阅读。
